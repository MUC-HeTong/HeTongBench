## 项目简介

HeTongBench 是和同（HeTong）开源生态规划中的评测基准体系，重点面向低资源多语种、多模态基础模型评测与可复现的能力分析。

**HeTongBench** 主要负责定义基准及其文档；**HeTongEval** 是计划用于运行评测与持续监测的平台；**HeTongRank** 是规划中的结果展示与排行榜体系。三者职责相互关联，但不混为一体。

## 规划中的基准方向

| 方向 | 关注能力 |
| --- | --- |
| 文本与多语种推理 | 文本理解、生成和跨语言推理 |
| 视觉语言 | 多模态感知、理解与推理 |
| 语音与音频 | 语音识别、音频语言理解 |
| 机器翻译 | 低资源及跨语言翻译能力 |
| 智能体 | 工具使用与多步任务执行 |
| 安全与文化理解 | 可靠性、文化语境理解与负责任的模型行为 |

初期研究重点拟覆盖藏文、蒙古文、维吾尔文及其他低资源语言。具体支持语言、语言变体、文字体系、任务与模态以未来正式发布的基准说明为准。

## 设计原则

- **可复现性：** 后续公开版本应明确数据和指标版本、提示词及评测配置。
- **语言规范：** 明确语言、方言或变体、文字体系及标注规则。
- **数据治理：** 发布前审查许可证、隐私、授权及数据污染风险。
- **科学比较：** 避免未经验证的跨任务综合排名与不恰当的性能结论。
